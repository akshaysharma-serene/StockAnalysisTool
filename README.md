# 📈 Local AI Stock Analysis Tool (Ollama + MCP + ML)

A local quantitative financial analysis system powered by **Ollama**, Anthropic's **Model Context Protocol (MCP)**, and **Scikit-Learn**. 

This system enables a local Large Language Model (e.g., `qwen2.5:7b`) to fetch real-time stock market data, calculate moving averages, and execute local machine learning trend forecasts—all operating locally without relying on external paid LLM APIs.
